    How to make a new skill.  Use when modifying an existing skill or when the user asks to make a new skill.
---

## Requirements

- Skill must must live in ~/.agents/skills/<name>/SKILL.md
- SKILL.md must have yaml frontmatter with two fields: `name` and `description`
- Description should be short and mention
    1. What the skill does
    2. When to use the skill

## Guidelines

- don't insert hard wraps into paragraphs
- prefer bullet points for most statements
- don't explain WHY something, just to DO something
