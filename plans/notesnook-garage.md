# Plan: Garage S3 on rumnas (Implementation in Progress)

## Goal

Get Garage running on rumnas at `garage.rum.internal`, with a web admin UI at `garage-web.rum.internal`, using the native NixOS `services.garage` module from nixpkgs.

## Status: Garage Module Created, Pending SOPS Secret & Deploy

---

## Architecture

```
garage.rum.internal  (Caddy :80 → localhost:3900)
  ├── S3 API         port 3900  — notesnook + future services
  ├── gRPC/RPC       port 3901  — internal cluster comms
  ├── Web hosting    port 3902  — S3 website endpoint
  └── Admin API      port 3903  — management endpoints

garage-web.rum.internal  (Caddy :80 → localhost:3904)
  └── garage-webui  port 3904  — admin web interface (host network)

Data:  /mnt/raid/services/garage/
Config: /etc/garage/garage.toml  (auto-generated by NixOS module)
```

## What's Pending (User Action Required)

### 1. Add SOPS secret

```bash
sops edit secrets/secrets.yaml
```

Add under `notesnook:`:
```yaml
  garage-rpc-secret: <run `openssl rand -hex 32` and paste the result>
```

### 2. Create data directories

```bash
sudo mkdir -p /mnt/raid/services/garage/{meta,data}
```

### 3. Deploy

```bash
nixos-rebuild switch --flake .#rumnas
```

### 4. Post-deploy

```bash
# Verify Garage is running
systemctl status garage
curl -s http://localhost:3900/

# Create the notesnook bucket (one-time)
podman exec garage garage bucket create attachments

# Check garage-webui
curl -s http://localhost:3904/
```

## Notes

- Garage runs as a native systemd service (not a container), so notesnook containers will connect to it via `127.0.0.1:3900` (host loopback)
- The `notesnook` podman network is created for future notesnook containers
- Garage web admin UI uses host networking (`--network=host`) to reach Garage on localhost
- Port 3904 is used for the webui to avoid conflicts with other services (8080 was considered but likely in use)
